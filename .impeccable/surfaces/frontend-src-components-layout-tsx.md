## Direction contract

THESIS: Replace Iris's saturated dashboard identity with Langfuse's restrained, hairline, data-forward system -- color lives in the data, not the chrome.

OWN-WORLD: Warm off-white ground; white hairline cards (1px border, minimal shadow, ~8px radius, down from shadow-lg/0.85rem); near-black ink for text and primary actions (no saturated brand hue); periwinkle-blue/gold/teal/green reserved for chart series and badges only; icon-only nav rail replacing the labeled sidebar; underlined text tabs; pill-shaped filters; Geist Sans/Mono retained.

STORY: A self-hoster scans real trace/eval data at a glance; a reviewer reads one coherent, deliberately restyled system, not a partial skin.

FIRST VIEWPORT: Icon rail left; header with page title + one primary action, no breadcrumb; hairline stat/chart cards in a responsive grid; charts carry the only saturated color.

FORM: Brief-pinned catalog world (Langfuse, via user-supplied screenshots) -- no concept-seed roll; direct translation per brief-wins, precedent already set by this project's own pinned-reference passes (Stakent, Black/Mahogany).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
